# Changelog

All notable changes to this plugin will be documented here.

## 0.1.0 — initial release

- Added the `port-github-app-to-origin` skill: discover a GitHub App's surface
  from its codebase, map it onto the live Origin API spec, and write a porting
  brief with a capability table, webhook field map, hello-world path, gap cards,
  and up-front questions.
